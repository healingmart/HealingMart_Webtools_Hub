어떤 웹도구를 제공하나요?

힐링편의점 웹도구는 특정 분야에만 한정하지 않고, 일상에서 자주 반복되는 작업을 빠르게 해결하는 방향으로 분류합니다. 계산기와 변환기처럼 도구 수가 많은 분야는 별도의 통합 모음으로 연결하고, 개별 기능은 필요한 카테고리에서 바로 찾을 수 있도록 구성합니다.

이미지 도구 이미지 자르기, 배경 제거, 워터마크, 파일명 정리, JPG·PNG·WebP 형식 변환 등 이미지 작업에 필요한 기능입니다.
영상 도구 영상 썸네일 추출, 파일 형식 변환, 용량 조절처럼 영상 제작과 정리에 필요한 보조 기능입니다.
글쓰기 도구 글자수와 단어수 확인, 공백과 줄바꿈 정리, 블로그 제목과 URL 정리 등 문서 작성에 유용한 기능입니다.
생활 도구 날짜, 금융, 건강, 단위와 생활 계산을 포함해 일상에서 바로 활용할 수 있는 계산기와 편의 기능입니다.
문서·변환 도구 PDF와 문서 파일을 합치거나 나누고, 이미지·문서·단위 형식을 서로 바꾸는 변환 기능입니다.
오디오 도구 MP3·WAV·M4A 형식 변환, 음원 정리, 자막 형식 변환처럼 오디오와 자막 작업에 필요한 기능입니다.
데이터 도구 위도와 경도, 표와 좌표, 데이터 형식을 정리하거나 변환할 때 사용하는 실용 기능입니다.
개발자 도구 JSON 정리와 검사, 코드 형식화 등 웹 제작과 데이터 확인에 필요한 간단한 개발 보조 기능입니다.

웹도구는 무료인가요?

이 페이지에 공개된 도구는 별도의 유료 프로그램 설치 없이 이용할 수 있도록 제공합니다. 외부 서비스나 API를 사용하는 기능은 해당 도구의 안내 조건이 우선 적용됩니다.

회원가입이 필요한가요?

대부분의 기본 웹도구는 로그인 없이 사용할 수 있도록 구성합니다. 외부 계정이나 별도 인증이 필요한 기능은 도구 화면에서 따로 안내합니다.

모바일에서도 사용할 수 있나요?

스마트폰과 태블릿에서도 검색, 카테고리 선택과 도구 실행이 가능하도록 반응형 화면을 적용합니다. 파일 처리 성능은 기기와 브라우저에 따라 차이가 날 수 있습니다.

원하는 도구가 보이지 않으면 어떻게 하나요?

검색어를 짧게 바꾸거나 관련 카테고리를 선택해 보세요. 아직 공개되지 않은 기능은 주소와 작동 상태를 확인한 뒤 순차적으로 추가합니다.

최근 사용한 도구 기록은 어디에 저장되나요?

최근 사용 기능은 같은 브라우저에서 도구를 다시 찾기 위한 용도로 동작합니다. 브라우저 저장공간을 삭제하거나 다른 기기를 사용하면 기록이 보이지 않을 수 있습니다.
