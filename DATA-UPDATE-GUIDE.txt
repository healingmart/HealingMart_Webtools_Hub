HealingMart Webtools v5.5.0 데이터 업데이트 규칙

총 도구 수
- 기본값: settings.baseToolCount = 1400
- 자동 추가값: available:true인 독립 도구 수
- 현재 계산: 1400 + 6 = 1406
- 일반 도구 하나를 추가하면 1407로 자동 증가
- 계산기 모음과 컨버터 모음은 includedInBase:true라서 추가 계산하지 않음

기존 카테고리에 도구 추가
1. data/hm-webtools-data.js의 tools 배열에 객체를 추가
2. category 값은 기존 category id 사용
3. available:true와 실제 url 입력
4. updatedAt 갱신

예시
{
  id: "image-watermark",
  name: "이미지 워터마크 도구",
  shortName: "워터마크",
  category: "image",
  description: "이미지에 글자 또는 로고 워터마크를 적용합니다.",
  keywords: ["워터마크", "로고", "저작권"],
  icon: "watermark",
  url: "실제 게시물 주소",
  available: true,
  includedInBase: false,
  updatedAt: "2026-07-25",
  order: 110
}

새 카테고리 추가
같은 data.js의 categories 배열과 tools 배열을 함께 수정합니다.

categories 배열 예시
{
  id: "ai",
  name: "AI 도구",
  description: "AI 활용과 자동화",
  icon: "developer",
  tone: "violet",
  order: 90
}

tools 배열의 도구에는
category: "ai"
를 사용합니다.

카테고리에 available:true인 도구가 하나 이상 생기면 허브에 자동 표시됩니다.
빈 카테고리는 자동으로 숨겨집니다.

Blogger 안전 처리
- 숫자 엔티티 사용 안 함
- 화살표 엔티티 사용 안 함
- 인라인 SVG 아이콘 사용
- innerHTML 사용 안 함
- CSS content는 빈 문자열만 사용
- 인라인 JavaScript를 CDATA 형식으로 감쌈
- 대표 이미지와 애드센스 위치 유지


data.js 반영 시간
- Blogger 게시물은 data.js를 5분 단위 캐시 키로 요청합니다.
- GitHub data.js를 수정하면 보통 즉시 또는 최대 약 5분 안에 새 요청으로 반영됩니다.
- Blogger HTML을 매번 수정할 필요는 없습니다.
- 외부 파일을 5초 안에 불러오지 못할 때만 게시물에 내장된 기본 데이터가 표시됩니다.
