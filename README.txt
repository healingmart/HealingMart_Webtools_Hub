HealingMart Webtools v5.5.0

변경 사항
- 전체 웹도구 숫자를 직접 연결 카드 수가 아닌 총 도구 수로 표시
- 기본 도구 수를 1,400개로 고정
- 새 독립 도구를 data.js에 추가할 때 총 숫자 자동 증가
- 계산기와 컨버터 카드에서 500/900 고정 숫자 제거
- 카테고리와 도구를 data.js 한 파일에서 관리
- Blogger 숫자 엔티티 및 특수문자 변환 대응 강화
- 모든 인라인 JavaScript를 CDATA 안전 형식으로 정리
- 이미지와 애드센스 위치 유지

적용 파일
- Blogger: blogger-webtools-with-image-adsense-v5.5.0.html
- GitHub: data/hm-webtools-data.js
- GitHub: js/hm-webtools-more.js

- data.js에 5분 단위 캐시 키 적용
- 외부 data.js 대기 시간을 5초로 조정
