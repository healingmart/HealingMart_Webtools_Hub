HealingMart Webtools v5.3.0

변경 사항
- 하단 메뉴 첫 번째에 힐링편의점 홈 추가
- 하단 메뉴: 홈 / 빠른찾기 / 최근사용 / 신규도구 / 카테고리
- 게시물 마지막 경계를 통과하면 하단 메뉴가 계속 숨겨짐
- 다시 위로 올라오면 하단 메뉴가 나타남
- 긴 SEO 설명을 게시물 하단의 접힌 안내 영역으로 이동
- 상단 웹도구 제목과 검색창을 계산기 모음처럼 크게 확장
- 우측 상단 공유 버튼 하나에서 여러 공유 채널을 열도록 통합
- 전체 개별 도구 목록을 무채색으로 변경
- 개별 도구의 웹도구 더보기 바텀시트도 무채색으로 변경
- 카테고리 카드의 제목을 크게 하고 중앙 정렬

Blogger 적용
1. 기존 웹도구 게시물을 HTML 보기로 엽니다.
2. 기존 코드를 전부 삭제합니다.
3. blogger-webtools-seo-post-v5.3.html 전체를 붙여 넣습니다.
4. 게시물을 저장합니다.

- js/hm-webtools-more.js

카카오톡
사이트에서 Kakao JavaScript SDK가 로드되어 있고 대표 이미지가 있으면 카카오 피드 공유를 사용합니다.
SDK가 없거나 대표 이미지가 없으면 기기 공유 또는 링크 복사로 대체됩니다.
